## 模拟结论

1. **召回决定可重排范围。** Test 中 Top-50 找到 344 个目标，Top-100 找到 478 个。DPO 召回负例组在 Top-50 中将 179 个目标排进前十，条件 HR@10 为 52.03%，端到端 HR@10 为 3.58%。按训练频次分层，零频目标在两种候选预算下的模拟召回率均最低。
2. **重排收益随训练方式变化。** Zero-shot Qwen 的 Test HR@10 比 CLIP 原顺序低 0.54 个百分点，融合高 0.16 个百分点。DPO 召回负例组比 CLIP 高 0.72 个百分点，比同一 SFT 起点的 DPO 随机负例组高 0.24 个百分点。后一个对照的模拟区间跨零。
3. **图像遮蔽的影响出现在候选内排序。** 遮蔽图像后，DPO 召回负例的 Test HR@10 从 3.58% 降到 3.36%，NDCG@10 从 1.95% 降到 1.81%。候选召回率固定在 6.88%。保留与遮蔽的模拟 HR@10 区间跨零，其幅度和方向仍需实际配对评估。
4. **扩大候选池有延迟代价。** 从 Top-50 到 Top-100，DPO 组的模拟 Test HR@10 增加 0.14 个百分点，重排 P95 从 5.58 秒增至 10.96 秒。HaNoRec 召回负例组在 Top-50 的 HR@10 比 DPO 组高 0.04 个百分点，二者 NDCG@10 均约 1.95%。

## 模拟计数核对示例

以 Test Top-50 的 DPO 召回负例组为例，前三名命中分别为 38、24、21，第四至第十名分别为 17、16、15、14、13、11、10。第 11–50 名命中 165 人，另外 4,656 人在候选外。前十命中共 179 人，除以 5,000 得 3.58%。按名次折扣求和再除以 5,000 得 NDCG@10 约 0.0195。条件 HR@10 使用相同的 179 个命中和 344 名召回命中用户，结果为 52.03%。
